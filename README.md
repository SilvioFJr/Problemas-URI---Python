# Problemas URI — Python

Soluções em **Python** para problemas da plataforma **URI Online Judge** (hoje [beecrowd](https://judge.beecrowd.com/)), da categoria *Iniciante*.

- 35 problemas resolvidos (1001–1049); cada arquivo `NNNN.py` corresponde ao problema de mesmo número.
- Exercícios de lógica, entrada/saída, condicionais e laços.

## Como executar

```bash
python3 1001.py
```

O programa lê a entrada pelo teclado (stdin), no formato pedido pelo enunciado do problema.
